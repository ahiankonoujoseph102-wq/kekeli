# Nettoyage professionnel : captures avant et après

Captures prises le 11 novembre 2026 sur un téléphone simulé (Pixel 7, navigateur en français) et sur un ordinateur (1440 × 900), avec des comptes et des projets inventés (`scripts/preparer-captures-nettoyage.php`, `scripts/captures-nettoyage.js`). La même réponse de Kekeli, avec ses défauts (espaces insécables, emoji, « code 200 », « php artisan test », noms de fichiers, phrase en double), sert pour les deux séries.

Le menu du compte s'ouvre seulement sur ordinateur dans le script : sur le téléphone, la capture « Menu du compte » montre la page sans le menu ouvert.
