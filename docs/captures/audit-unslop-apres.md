# Audit unslop : avant et après

Captures prises le 14 novembre 2026, **avant** l'audit (`audit-unslop/ecrans/`) et **après les neuf passes** (`audit-unslop/apres/`), sur un téléphone simulé (Pixel 6) et sur un ordinateur, en clair et en sombre, avec les mêmes données inventées. Le détail de chaque passe, avec ses mesures : [`audit-unslop-passes.md`](audit-unslop-passes.md) ; le plan : [`docs/audit-unslop.md`](../audit-unslop.md).

Les réponses montrées dans les discussions sont celles enregistrées dans les données d'exemple : la nouvelle consigne du gras (passe 4) ne s'applique qu'aux nouvelles réponses.
